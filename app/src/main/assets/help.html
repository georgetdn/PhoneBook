Using Phone Book

Enter a request in the text field at the bottom of the conversation screen, then tap Send. Your request and the app's reply appear in the conversation area.

Example contact requests

  • Find Jane Smith — find entries by first and last name.
  • Add Jane Smith, +1 202-555-0101 — add a contact using a name and phone number.
  • Edit entry 12 — identify the entry to edit by its ID.
  • Delete entry 12 — identify the entry to delete by its ID.

Find an entry before editing or deleting

First find the person by name. Use the ID shown in the results to identify the specific entry for an edit or deletion. This matters when more than one entry has the same name. The app asks for confirmation before deleting an entry.

Blank requests

The app does not accept a blank request. Enter a request before tapping Send.

Current build note

The current Phone Book screen displays submitted requests and a placeholder acknowledgment. Contact searching, adding, editing, and deleting are not connected yet, so the examples above describe the intended commands and will work when that command handling is added.

Exit

Tap Exit in the app bar to close Phone Book.
